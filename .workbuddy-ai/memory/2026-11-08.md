## GitHub 三端打包流水线（Android / Windows / macOS）

**背景**：仓库 `hakimi-x/Orange`（FlClash fork，app 名 mxycloud，包名 com.follow.DreamCloud）。
项目只有 android/linux/macos/windows，**没有 ios/ 目录**，iOS 无法打包。

**关键事实**
- 打包入口：`dart setup.dart <android|windows|macos|linux> [--arch amd64|arm64|arm] [--universal] [--env stable]`
- `setup.dart` 用 Go 编译核心（android 为 c-shared，需 NDK clang；其余为 exe 模式 CGO_ENABLED=0）
- Windows 额外需 Rust（`services/helper` 的 `cargo build --release --features windows-service`）+ Inno Setup（exe 产物）
- macOS 需 `appdmg`（npm），`--universal` 走 arm64+amd64 双核心 + `lipo` 合并
- Android 需 NDK **28.0.13004108**、compileSdk **36**（`android/app/build.gradle.kts`）
- 三个 submodule：core/Clash.Meta、plugins/flutter_distributor、lib/sdk/flutter_xboard_sdk，CI 必须 `submodules: recursive`
