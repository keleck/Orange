# 订阅服务使用示例

## 基本使用（推荐）

### 1. 获取订阅（自动处理一切）

```dart
import 'package:fl_clash/xboard/features/subscription/subscription.dart';

// 最简单的方式：自动处理去重、限流、重试、竞速
Future<void> updateSubscription() async {
  try {
    final result = await EncryptedSubscriptionService.getEncryptedSubscriptionFromLogin(
      preferEncrypt: true,  // 优先使用加密端点
      enableRace: true,     // 启用多源竞速
    );
    
    if (result.success) {
      print('订阅内容: ${result.content}');
      print('使用加密: ${result.encryptionUsed}');
      print('密钥: ${result.keyUsed}');
      print('订阅URL: ${result.originalUrl}');
      print('流量信息: ${result.subscriptionUserInfo}');
    } else {
      print('获取失败: ${result.error}');
    }
  } catch (e) {
    if (e is SubscriptionRequestBlockedException) {
      // 熔断器开启，服务暂时不可用
      print('服务暂时不可用: ${e.message}');
    } else {
      print('异常: $e');
    }
  }
}
```

## 错误处理最佳实践

### 1. 用户友好的错误提示

```dart
String getUserFriendlyErrorMessage(dynamic error, SubscriptionResult? result) {
  if (error is SubscriptionRequestBlockedException) {
    return '服务暂时不可用，请稍后重试';
  }
  
  if (result != null && !result.success) {
    final errorMsg = result.error ?? '';
    
    if (errorMsg.contains('404')) {
      return '订阅链接暂时无法访问，正在重试...';
    } else if (errorMsg.contains('429')) {
      return '请求过于频繁，请稍后再试';
    } else if (errorMsg.contains('timeout') || errorMsg.contains('超时')) {
      return '网络连接超时，请检查网络设置';
    } else if (errorMsg.contains('token')) {
      return '订阅令牌无效，请重新登录';
    } else if (errorMsg.contains('解密')) {
      return '订阅数据解密失败，请联系管理员';
    } else {
      return '更新失败，请稍后重试';
    }
  }
  
  return '未知错误: $error';
}
```

## 性能优化技巧

### 1. 避免重复调用

```dart
// ❌ 错误：快速多次调用
Future<void> badExample() async {
  for (int i = 0; i < 5; i++) {
    await EncryptedSubscriptionService.getEncryptedSubscriptionFromLogin();
  }
}

// ✅ 正确：依赖请求管理器自动去重
Future<void> goodExample() async {
  // 即使多次调用，也会自动去重
  final futures = List.generate(5, (_) => 
    EncryptedSubscriptionService.getEncryptedSubscriptionFromLogin()
  );
  
  final results = await Future.wait(futures);
  // 实际上只发起了一次请求，其他请求复用结果
}
```

### 2. 预检查避免无谓请求

```dart
Future<void> smartUpdate() async {
  final manager = SubscriptionRequestManager();
  final status = manager.getStatus();
  
  // 检查熔断器状态
  if (status['circuitBreakerOpen'] == true) {
    print('服务暂时不可用，跳过更新');
    return;
  }
  
  // 检查是否有正在进行的请求
  if (status['hasOngoingRequest'] == true) {
    print('已有正在进行的更新，跳过');
    return;
  }
  
  // 检查最后成功时间
  final lastSuccess = status['lastSuccessTime'];
  if (lastSuccess != null) {
    final lastTime = DateTime.parse(lastSuccess as String);
    if (DateTime.now().difference(lastTime).inMinutes < 5) {
      print('5分钟内已成功更新，跳过');
      return;
    }
  }
  
  // 执行更新
  await EncryptedSubscriptionService.getEncryptedSubscriptionFromLogin();
}
```

## 常见问题

### Q: 为什么第一次请求很慢？
A: 第一次请求可能包含域名竞速，需要测试多个源。后续请求会更快。

### Q: 熔断器开启后如何快速恢复？
A: 等待30秒自动恢复，或调用 `SubscriptionRequestManager().reset()` 手动重置。

### Q: 如何判断是API问题还是客户端问题？
A: 查看日志中的错误响应体内容。如果返回具体的错误消息（如"token invalid"），则是API问题；如果是"连接超时"、"连接被拒绝"，则是网络问题。

### Q: 重试5次还是失败怎么办？
A: 
1. 检查网络连接
2. 检查token是否有效
3. 手动在浏览器访问订阅URL确认API是否正常
4. 查看服务器日志确认是否有限流或封禁

### Q: 可以跳过请求管理器直接请求吗？
A: 可以，但不推荐。调用 `_getEncryptedSubscriptionFromLoginInternal` 内部方法可以跳过请求管理器，但会失去去重、限流和熔断保护。
